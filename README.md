# mygit · 3D Cymatic Particle Hero Platform

Modern React application featuring a 3D Cymatic acoustic particle sculpture morphing through 10 resonance forms every 2 seconds.

## Built With
- **React 19**
- **TypeScript**
- **Vite**
- **Tailwind CSS v4**
- **Slider Revolution Anywhere & Three.js**

## Deployment
Configured for automated Netlify deployment via `netlify.toml`:
- **Build command**: `npm run build`
- **Publish directory**: `dist`

## Development
```bash
npm install
npm run dev
```

## Production Build
```bash
npm run build
```
